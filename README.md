# Бот-тест на определение уровня английского (v2, с опцией «Я не знаю»)

Это **отдельный, независимый бот** — он не связан с предыдущим ботом
`Test_by_Englishizer_bot` и никак не может с ним конфликтовать, если вы
будете следовать этой инструкции: у него будет свой аккаунт в BotFather
(свой токен), свой репозиторий на GitHub и свой сервис на Render. Три
разных системы, три разных набора учётных данных — пересечься им негде.
Старый бот можно продолжать использовать как есть, ничего в нём менять не нужно.

## Что нового по сравнению с первой версией

У каждого из 50 вопросов теперь есть пятая кнопка — **«🤷 Я не знаю»**.
Она не засчитывается как правильный ответ (и не может быть угадана правильно),
но избавляет ученика от необходимости гадать наугад между a/b/c/d. В конце
теста бот также показывает, сколько раз ученик выбрал «не знаю» — это
дополнительно сохраняется в Google Таблицу и в уведомление админу.

## Частые ошибки прошлого проекта — и как этот бот от них защищён

При работе над первым ботом было три сбоя. Здесь прямо объясняю, что было,
чтобы вы не наступили на те же грабли во втором боте:

1. **Локальный запуск ломал прод.** Если запустить `python bot.py` на своём
   компьютере с тем же токеном, что стоит на Render, это удаляет вебхук
   продовой версии — бот переставал отвечать ученикам. В этом боте я оставил
   предупреждение прямо в консоли при локальном запуске, но лучше вообще не
   рисковать: **для локальных тестов заведите отдельного, третьего бота**
   через BotFather (например, `@your_name_test_bot`) и используйте его токен
   только на своём компьютере. Токен продового бота — только на Render.

2. **Токен был случайно отозван.** В BotFather в меню бота рядом с «API Token»
   есть кнопка «Revoke current token» — если случайно нажать её вместо
   «API Token», бот перестаёт работать полностью (ошибка 401 Unauthorized).
   Перед тем как нажать что-либо в меню бота, читайте название кнопки.

3. **Токен скопирован не от того бота.** Если в BotFather в списке `/mybots`
   несколько ботов, легко скопировать токен не от того, что нужно. Прежде
   чем копировать API Token, убедитесь, что в шапке экрана BotFather
   написано именно то имя бота, для которого вы собираете токен.

4. **Бесплатный тариф Render "засыпает".** Без обращений 15 минут сервис
   останавливается и просыпается ~50 секунд — за это время сообщение ученика
   может не дойти, а прогресс уже начатого тем учеником теста (хранится в
   памяти сервиса) сбрасывается. Поэтому в инструкции ниже сразу
   используется платный тариф **Starter ($7/мес)** — на нём сервис работает
   постоянно, без задержек и потери прогресса.

## Шаг 1. Создать нового бота в Telegram (2 минуты)

1. Откройте Telegram, в поиске введите `BotFather`.
2. Отправьте `/newbot`.
3. Введите название — то, что видит ученик, например `Тест на уровень английского 2`.
4. Введите username — обязательно заканчивается на `bot`, например
   `your_name_level_test_bot`. Постарайтесь дать ему имя, явно отличающееся
   от старого `test_by_Englishizer_bot`, чтобы не путать их между собой.
5. BotFather пришлёт токен вида `7123456789:AAHk3vF...` — скопируйте и
   сохраните его в заметках. Это токен НОВОГО бота — он никак не связан со
   старым.

⚠️ Токен — как пароль. Не публикуйте его нигде, кроме Render (шаг 4).

## Шаг 2. Узнать свой chat_id (1 минута)

Нужно, чтобы бот знал, кому присылать заявки.

1. В Telegram откройте `@userinfobot`, нажмите **Start**.
2. Скопируйте число из строки `Id: 123456789` — это `ADMIN_CHAT_ID`.
3. Откройте вашего нового бота (из шага 1) и нажмите **Start** — без этого
   Telegram не разрешит боту писать вам первым.

## Шаг 3. Выложить код на GitHub — в НОВЫЙ репозиторий (5-10 минут)

1. На [github.com](https://github.com) нажмите **New** → **New repository**.
2. Название — например, `level-test-bot-v2` (не используйте имя старого
   репозитория и не заливайте эти файлы в старый репозиторий).
3. Repository **Public**, остальное по умолчанию → **Create repository**.
4. На открывшейся странице — **uploading an existing file** (или
   **Add file → Upload files**).
5. Перетащите все файлы из этой папки: `bot.py`, `questions.py`, `sheets.py`,
   `config.py`, `requirements.txt`, `render.yaml`, `runtime.txt`,
   `apps_script.gs`, `.gitignore`, `.env.example`, `README.md`.
6. **Commit changes**.

## Шаг 4. Задеплоить на Render — в НОВЫЙ сервис (10 минут)

1. На [render.com](https://render.com) → **New +** → **Web Service**.
2. Выберите репозиторий `level-test-bot-v2` → **Connect**.
3. Render подхватит `render.yaml`. В нём уже стоит план **Starter** — это
   платный тариф без "засыпания" (см. причину 4 выше). Если хотите начать
   с бесплатного, чтобы просто проверить, что всё работает, можно временно
   поставить **Free** в настройках плана — но для реальной работы со
   студентами переключите на **Starter**.
4. В разделе **Environment Variables** добавьте:

   | Key | Value |
   |---|---|
   | `BOT_TOKEN` | токен НОВОГО бота из шага 1 (не старого!) |
   | `ADMIN_CHAT_ID` | число из шага 2 |
   | `BOOKING_URL` | ссылка на запись — например, `https://t.me/ваш_username` |

   `GOOGLE_SCRIPT_URL` пока не добавляйте.
5. **Create Web Service**, дождитесь статуса **Live**, скопируйте адрес
   вида `https://level-test-bot-v2-xxxx.onrender.com`.
6. В **Environment** добавьте `WEBHOOK_URL` = этот адрес без `/` на конце.
7. **Save Changes** — Render передеплоит бота.

## Шаг 5. Проверить

1. Откройте вашего нового бота, отправьте `/start`.
2. Пройдите тест — попробуйте на паре вопросов нажать «Я не знаю», убедитесь,
   что тест не засчитывает это как правильный ответ.
3. Введите тестовое имя и телефон, проверьте, что заявка пришла вам в личные
   сообщения от бота.

Если что-то не работает — смотрите вкладку **Logs** в Render, и первым делом
проверьте `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getWebhookInfo` в браузере
(вставьте токен нового бота вместо `<ВАШ_ТОКЕН>`, без `< >`).

## Локальный запуск (только с отдельным тестовым ботом!)

```bash
pip install -r requirements.txt
cp .env.example .env
# впишите в .env токен ОТДЕЛЬНОГО тестового бота (не продового!) и ADMIN_CHAT_ID
# WEBHOOK_URL оставьте пустым
python bot.py
```

## (Необязательно) Google Таблица

1. Создайте таблицу на [sheets.google.com](https://sheets.google.com).
2. **Extensions → Apps Script**, вставьте код из `apps_script.gs`.
3. **Deploy → New deployment** → **Web app** → Execute as **Me** →
   Who has access **Anyone** → **Deploy**.
4. Скопируйте URL, добавьте на Render переменную `GOOGLE_SCRIPT_URL`.

## Изменить вопросы или уровни

Вопросы — в `questions.py`, переменная `QUESTIONS`. Шкала уровней —
`LEVEL_BANDS` в том же файле. Кнопка «Я не знаю» добавляется автоматически
к каждому вопросу в `bot.py` (функция `question_keyboard`) — трогать
`questions.py` для этого не нужно.
